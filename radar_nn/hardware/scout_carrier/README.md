# Плата-носитель разведчика, вариант Б (ESP32-S3 без камеры)

Плата по контуру самой ESP32-S3: **28 × 61,5 мм** под YD-ESP32-S3 (25,5 × 61,5 мм под
DevKitC-1). Одна сторона меди, без перемычек и переходных отверстий — под ЛУТ или
фоторезист. ESP32-S3 стоит сверху в гнёздах, **гироскоп GY-521 и компас лежат под ней**,
между рядами штырей. Радар подключается угловым разъёмом с торца со стороны USB.

```
       ┌──────── ESP32-S3 (в гнёздах 8,5 мм) ────────┐
       │  ▓▓ GY-521 ▓▓   ▓ компас ▓                   │  ← модули на своих штырях, ~5 мм
  ═════╧═══════════════════════════════════════════╧═══ ← плата-носитель, медь снизу
                                                     └─ угловой разъём радара
```

Под ESP32-S3 остаётся около 11 мм: гнездо 8,5 мм плюс пластик её штырей 2,5 мм. Модуль,
лежащий на своих штырях, занимает около 5 мм.

Двусторонняя плата не понадобилась: при таком выборе выводов всё разводится на одной
стороне. Для домашнего изготовления это проще: не нужно совмещать слои, а в гнёзда,
которые паяются только снизу, всё равно нельзя завести дорожку сверху.

```
gen_board.py                 генератор: геометрия, проверка зазоров и связности, все файлы
out_yd_25.40/                YD-ESP32-S3 (ряды штырей через 25,4 мм)
out_devkitc_22.86/           ESP32-S3-DevKitC-1 (ряды через 22,86 мм)
    print.pdf                3 листа A4 в масштабе 1:1: медь (4 копии), негатив (4 копии), сборка
    copper_lut.svg           медь (чёрное — медь)
    copper_negative.svg      негатив (белое — медь)
    assembly.svg             расстановка деталей с подписями выводов
    gerber/                  Gerber нижнего слоя и контура, сверловка Excellon — для станка или завода
```

Дорожки 0,8 и 1,0 мм, минимальный зазор 0,74 мм, площадки 1,8 мм, отверстия 1,0 мм.

## Какой вариант печатать

Измерьте расстояние между рядами штырей своей ESP32-S3 (от центра штыря до центра штыря
напротив):
- **25,4 мм** — `out_yd_25.40` (YD-ESP32-S3, «N16R8» с двумя USB-C);
- **22,86 мм** — `out_devkitc_22.86` (Espressif DevKitC-1). Между рядами здесь меньше
  места: GY-521 шире 20 мм может упереться в гнёзда, поэтому измерьте модуль.

Надёжнее всего распечатать лист «Сборка» и приложить ESP32-S3 штырями к рисунку.

## Подключение

| Узел | Вывод ESP32-S3 | На плате |
|---|---|---|
| GY-521 и компас: SCL / SDA | **GPIO17 / GPIO18** | ряды под ESP32-S3 |
| GY-521 и компас: VCC / GND | 3V3 / GND | |
| Радар: TX радара → | **GPIO13** (приём ESP) | разъём, 4-й штырь «TX рад.» |
| Радар: RX радара ← | **GPIO14** (передача ESP) | 3-й штырь «RX рад.» |
| Радар: 5V / GND | 5V / GND | 2-й / 1-й штырь |

Выводы выбраны так, чтобы дорожки не пересекались. `rescue_scout.ino` для «ESP32S3 Dev
Module» уже настроен на них. Без платы, на проводах, подключайте к тем же выводам.

## Детали

| Поз. | Что | Кол-во |
|---|---|---|
| — | Стеклотекстолит односторонний 1,5 мм, 32 × 65 мм | 1 |
| J1, J3 | Гнездо 1×22 «мама», шаг 2,54 (или отрезать от 1×40) | 2 |
| XG | GY-521 на своих штырях (8 шт.) — впаять в плату | 1 |
| XC | Компас GY-273 / GY-271 на своих штырях (5 шт.) — по желанию | 1 |
| XR | Штыри 1×4 «папа» **угловые** (90°) + кабель Dupont «мама–мама» к радару | 1 |

## Изготовление

**Печать.** Печатайте `print.pdf` в масштабе **100%**. Проверьте линейкой полосу 50 мм.

**Не зеркалить.** Медь снизу, а лист нарисован видом сверху: при переносе тонера или
плёнки рисунок отразится сам. Проверка — надпись SCOUT-S3: на листе она зеркальная, на
готовой плате со стороны меди читается нормально.

- **ЛУТ** и аэрозольный (позитивный) фоторезист — лист 1.
- **Плёночный (негативный) фоторезист** — лист 2.

**Вырезать по рамке точно.** Площадки рядов стоят в 0,4 мм от края: плата должна быть не
шире самой ESP32-S3.

**Порядок сборки:**
1. Сначала модули, потом гнёзда: после гнёзд к модулям не подобраться.
2. **GY-521** лежит над платой на своих штырях, корпусом к USB. Штыри короткой стороной
   вниз в плату, модуль лежит на пластике штырей. Сверьте подписи выводов на модуле с
   листом «Сборка»: VCC, GND, SCL, SDA, XDA, XCL, AD0, INT. Если порядок получается
   обратный, переверните модуль деталями к плате, место под ним есть. Положение
   гироскопа прошивке безразлично.
3. **Компас** — так же, корпусом к USB: VCC, GND, SCL, SDA, DRDY.
4. Проверить высоту: верх модулей должен быть не выше 8 мм над платой.
5. Гнёзда 1×22 — сверху, паять снизу.
6. Угловой разъём радара — с торца у USB, штырями наружу.

## Проверки перед включением

1. **Прозвонить** соседние дорожки на замыкание — особенно у разъёма радара.
2. **5V на YD-ESP32-S3.** ESP32-S3 в гнёздах, модулей пока можно не впаивать, USB подключён.
   Между 5V и GND разъёма радара должно быть 4,7–5,1 В. Если 0 В — на YD-ESP32-S3 рядом с
   USB ищите перемычку **«IN-OUT»** и замкните её. Радару нужно 5 В.
3. **RGB-светодиод** (подсказка пилоту) на YD-ESP32-S3 не светится — замкнуть перемычку «RGB».
4. Прошить `rescue_scout.ino` (плата «ESP32S3 Dev Module»). В мониторе порта:
   `вариант: ESP32-S3, без камеры`, `gi` — гироскоп найден (0x68), `i` — компас, если стоит.

## Если нужно изменить

Геометрия — в `gen_board.py` (функция `build`). После правок:

```
python gen_board.py
```

Скрипт проверит зазор между разными цепями (≥ 0,5 мм), медь у края, что каждая цепь —
один кусок меди. При ошибке напишет, что и где. Листы `print.pdf` собираются из
`print.html` в браузере: «Печать → Сохранить как PDF», масштаб 100%.
